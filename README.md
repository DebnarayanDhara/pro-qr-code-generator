# 🔳 Pro QR Code Generator

A professional Python QR Code Generator with advanced features.  
This project allows you to generate customized QR codes with options for colors, logos, formats, and batch processing.

---

## ✨ Features
- Generate QR codes from text or URLs
- Step‑by‑step interactive input (no complex flags needed)
- Custom foreground/background colors
- Save as PNG, JPG, or SVG
- Embed logos inside QR codes
- Adjustable error correction levels (L, M, Q, H)
- Batch generation from CSV files
